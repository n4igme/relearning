## Quests

### 1. JavaScript Fundamentals Quiz
- **Course**: Full-Stack Web Development Bootcamp
- **Description**: Test your knowledge of JavaScript basics.
- **Passing Score**: 70
- **Time Limit**: 30 minutes
- **Questions**:
  1. **What is a closure in JavaScript?** (Multiple Choice)
     - A function with access to parent scope (Correct)
     - A way to close a program
     - A loop structure
     - A type of variable
  2. **Which method adds an element to the end of an array?** (Multiple Choice)
     - push() (Correct)
     - pop()
     - shift()
     - unshift()

### 2. React Hooks Quiz
- **Course**: Full-Stack Web Development Bootcamp
- **Description**: Test your knowledge of React Hooks.
- **Passing Score**: 70
- **Time Limit**: 20 minutes
- **Questions**:
  1. **Which hook is used for side effects?** (Multiple Choice)
     - useState
     - useEffect (Correct)
     - useContext
     - useRef

### 3. Machine Learning Concepts Quiz
- **Course**: Machine Learning with Python
- **Description**: Test your ML fundamentals.
- **Passing Score**: 70
- **Time Limit**: 30 minutes
- **Questions**:
  1. **What is overfitting?** (Multiple Choice)
     - Model performs well on training but poorly on test data (Correct)
     - Model performs poorly on both
     - Model trains too quickly
  2. **Is supervised learning used when you have labeled data?** (True/False)
     - True (Correct)
