# CyberSec Academy Learning Paths

## Overview

CyberSec Academy offers two primary learning paths to help you specialize in cybersecurity:

1. **🔴 Offensive Security** - Ethical Hacking & Penetration Testing
2. **🔵 Defensive Security** - Security Operations & Blue Team

Some courses cover foundational skills applicable to both paths (marked as **🟣 Both Tracks**).

---

## 🔴 Offensive Security Path

### Focus Areas
Learn to think like an attacker to better protect systems. This path teaches ethical hacking, penetration testing, and offensive security techniques.

### Core Skills
- Web Application Security
- Reverse Engineering
- Malware Analysis
- Exploitation Techniques
- Penetration Testing Methodologies

### Career Paths
- Penetration Tester
- Security Researcher
- Bug Bounty Hunter
- Red Team Operator
- Exploit Developer

### Recommended Course Progression

**Beginner Level:** (~30-40 hours total)
1. Introduction to Ethical Hacking (10-15 hours)
2. Web Application Security Fundamentals (10-12 hours)
3. Network Reconnaissance & Scanning (8-10 hours)

**Intermediate Level:** (~50-60 hours total)
1. Web Application Penetration Testing (15-20 hours)
2. Network Penetration Testing (15-20 hours)
3. Wireless Security Assessment (12-15 hours)

**Advanced Level:** (~60-80 hours total)
1. Advanced Exploitation Techniques (20-25 hours)
2. Reverse Engineering & Binary Analysis (20-25 hours)
3. Malware Development for Red Teams (20-25 hours)

---

## 🔵 Defensive Security Path

### Focus Areas
Learn to defend systems, detect threats, and respond to security incidents. This path teaches defensive security, threat hunting, and blue team operations.

### Core Skills
- Network Security
- Digital Forensics
- Cloud Security
- Incident Response
- Security Monitoring & SIEM

### Career Paths
- SOC Analyst
- Incident Responder
- Threat Hunter
- Digital Forensics Analyst
- Security Operations Manager

### Recommended Course Progression

**Beginner Level:** (~30-40 hours total)
1. Introduction to Blue Team Operations (10-15 hours)
2. Network Security Fundamentals (10-12 hours)
3. Security Monitoring Basics (8-10 hours)

**Intermediate Level:** (~50-60 hours total)
1. Security Operations Center (SOC) Analyst (15-20 hours)
2. Threat Detection & Analysis (15-18 hours)
3. Cloud Security Fundamentals (12-15 hours)

**Advanced Level:** (~60-80 hours total)
1. Incident Response & Forensics (20-25 hours)
2. Advanced Threat Hunting (20-25 hours)
3. Security Architecture & Design (20-25 hours)

## 🟣 Foundational Skills (Both Tracks)

Some courses provide foundational knowledge essential for both offensive and defensive security roles:

### Cryptography
- Understanding encryption algorithms
- Public Key Infrastructure (PKI)
- Cryptographic attacks and weaknesses
- **Career Impact**: Essential for both attackers (breaking crypto) and defenders (implementing secure crypto)

### Social Engineering
- Phishing and pretexting techniques
- Physical security assessment
- Human psychology in security
- **Career Impact**: Red teams use it for access; blue teams defend against it

## Choosing Your Path

### Start with Offensive Security if you:
- Enjoy breaking systems and finding vulnerabilities
- Want to work in penetration testing or bug bounties
- Prefer creative, hands-on problem solving
- Are interested in exploit development

### Start with Defensive Security if you:
- Enjoy protecting systems and analyzing threats
- Want to work in SOC or incident response
- Prefer structured processes and methodologies
- Are interested in security monitoring and forensics

### Can't Decide?
Start with **foundational courses** (Cryptography, Social Engineering, or general security courses) to build baseline knowledge, then explore both paths through beginner-level courses before specializing.

---

## Dual-Path Mastery

Many cybersecurity professionals excel by understanding both offensive and defensive techniques:

- **Purple Team**: Combines red team (offensive) and blue team (defensive) skills
- **Security Architect**: Needs offensive mindset to design defensible systems
- **Threat Intelligence Analyst**: Uses offensive knowledge to understand attackers

**Recommended Approach:**
1. Choose one path to specialize in first (6-12 months)
2. Build strong foundation in your chosen area
3. Cross-train in the opposite path to broaden perspective
4. Combine skills for advanced roles

If you're unsure which path to start with:
